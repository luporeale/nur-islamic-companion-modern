# Nūr – Compagno Islamico (Modern)

Versione moderna, illustrativa e animata del compagno islamico Nūr.

- Design contemporaneo con gradienti, glassmorphism e animazioni fluide
- Pattern geometrici islamici
- Sezioni per Corano, Orari di Preghiera, Qibla, Adhkar, Hadith e Assistente
- Esperienza calma e rispettosa
